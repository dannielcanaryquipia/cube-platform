# Layer by Layer

A clean, ad-free learning site for the 3x3 CFOP method, built with React and Vite.

- **Notation**: every face, prime, double, wide, slice (M E S) and rotation (x y z) move, each shown on a 3D cube, with a finger-trick tip. You can type your own moves and watch them.
- **F2L** (41 cases), **Advanced F2L** (front-left and back slots without rotations), **OLL** (57) and **PLL** (21).
- Every case has a recognition diagram and an algorithm. Open a case to watch it on a 3D cube with play, pause, step back/forward, jump-to-move and speed control.
- Search across everything by name ("T perm", "OLL 27"), shape ("fish"), group ("corner in slot") or alg text ("R U R' U'"). Filter each set by category and by your progress.
- Mark cases as Learning or Learned. Progress is saved in your browser.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/, works from any folder (hash routing, relative paths)
```

## How it fits together

- `src/lib/cube.js`: a small sticker-level 3x3 simulator. It draws the case diagrams and checks the algorithms.
- `src/data/ll.js`: OLL and PLL algorithms. `src/data/f2l.json`: F2L cases, generated by `scripts/gen-f2l.mjs`.
- `src/components/CubePlayer.jsx`: the 3D player, built on the [cubing.js](https://js.cubing.net/cubing/) twisty player.
- `npm run verify` checks that every OLL and PLL alg is valid and that no two solve the same case.

Orientation everywhere: white cross on the bottom, yellow on top, green in front.
